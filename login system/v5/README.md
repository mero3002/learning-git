### What I have learned throughout this project:
#### For Python:
1. Polished some weak parts such as dealing with text and JSON files and error handling.
2. Got better generally coding in python.
#### General Lessons:
1. Coding alone is not everything, building a solid strategy and algorithm of how your program should operate is mandatory.
2. Design your code in such a way that it allows adding new features even if you don't intend adding some.
3. Abstraction is the key, simplify each function's task, no function should have "and" or "or" in its name, the simpler the functions are the more your code implementation becomes as easy as playing with Legos.
