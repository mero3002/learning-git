###### Introducing Roles and access control:
- There are 3 session modes, *Admin*, *User* (who already has an account) and *Guest* (who is new to our thing) (yeah, a thing, what should i even call it) (i should prolly stop recursively using bracket contexts before it's too late) (now what's 5!) - **Admin** -> no one dares to ask him for his actions (permission granted for everything).
- **User** -> can freely display and modify his account info.
- **Guest** -> can login or create an account to become a user, besides an option to enter admin mode.
- To each his own list of options, Admin and User can logout of their sessions to become Guest, and from there, they're free to choose their role again.
- Admin Token (password) will be in a separate `.txt` file, also changeable from there.
